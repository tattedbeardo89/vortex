# Vortex

Vortex — независимое оформление приложения Overdrive, созданного MyLuxy, на базе PS5 React (half144 и участники проекта).

Репозиторий: https://github.com/tattedbeardo89/vortex. Пакет: **Vortex.exfat**. Идентификатор: **PPSA99189**. Не заменяйте Overdrive.exfat: приложения должны устанавливаться отдельно. Проверка на реальной PS5 ещё требуется.

Актуальные инструкции: [README.md](README.md), [сборка](docs/BUILDING.md), [обновления](docs/UPDATING.md). Исходная русская документация и благодарности сохранены в [docs/UPSTREAM_README.ru.md](docs/UPSTREAM_README.ru.md).
